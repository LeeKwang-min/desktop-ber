# 미뤄둔 항목 (리뷰에서 나온 Minor)

계획 A·B 최종 리뷰에서 나왔지만 고치지 않고 미뤄둔 것들. 관련 코드를 다시 건드리는 계획에서 처리한다.

## 계획 D에서 처리함
- CSP 켬, 쓰다듬는 동안 히트 판정 최대 15Hz로 제한
- 릴리스 빌드 쉬는 중 CPU: ber 1.3% + WebKit 2.4% = 3.8% (목표 5% 미만 달성, Apple Silicon·화면 1개·식빵 12fps). 메모리 약 190MB

## 기회가 될 때
- 스냅샷에서 복원할 때 식빵이 아닌 모든 자세를 '잠'으로 표시함 (걷던 중 재구성되면 5~15초 '자는' 상태로 서 있음) — `lieSide`/`curl`만 잠으로
- `pointerdown`이 오른쪽·ctrl 클릭도 쓰다듬기로 셈, 클릭 순간 히트를 다시 확인하지 않음 — `e.button === 0 && view.hitTest(...)`
- 깨진 설정 파일은 다음 트레이 변경 때에야 기본값으로 덮어씀 (사용자 차이 없음) — 시작 시 `save(app, &load(app))`
- 귀찮음 10초 경계(9.5초엔 무시, 10.5초엔 반응)를 정확히 고정하는 테스트가 없음

## 계획 C 리뷰에서 (기회가 될 때)
- 낮잠 중인 창이 오른쪽에서 줄어들면 베르가 제목 표시줄 끝을 넘어선 채 붙어 있을 수 있음 — x가 창 밖이면 "창 사라짐"과 같이 처리
- 낮잠 창이 사라질 때 spec §6.6의 0.3초 폴짝 점프 없이 그 자리에서 일어남 (외형 단순화)
- 크기 '크게'(180px)에서 낮잠 자리가 창 윗변에서 45px 아래 — spec §6.3의 16~40px 띠를 벗어남, 범위로 자르기
- 창을 드래그할 때 베르가 최대 ~170ms 늦게 따라옴 (10Hz 창 목록 + 쉬는 중 15fps) — 낮잠 중엔 창 이벤트가 오면 즉시 한 번 갱신
- 창 밑에 있는 동안 `setOccluders`가 매 프레임 메시를 새로 만듦 — 사각형이 그대로면 건너뛰기
- 테스트 보강: 숨은 창이 사라지거나 크기가 바뀌는 경우, 낮잠 '창 닫힘' 루프가 아무 시드도 못 찾으면 실패하게, 가림막 계산을 순수 함수로 빼서 테스트
- `CGWindowListCopyWindowInfo`가 NULL일 때 로그 없이 빈 목록 (spec §10은 로그를 남기라고 함)

## 계획 D 리뷰에서 (기회가 될 때)
- Windows: 다른 데스크톱 펫·게임 오버레이·화상 키보드가 낮잠/숨기 대상이 될 수 있음 — `WS_EX_NOACTIVATE`이면서 `WS_EX_APPWINDOW`가 없는 창, `WS_EX_TRANSPARENT` 창도 `is_user_window`에서 제외
- Windows: 창 목록을 만들 때 보이지 않거나 최소화된 창도 DWM·클래스 이름·제목 길이를 다 조회함 — `!IsWindowVisible || IsIconic`이면 먼저 건너뛰기
- Scoop `autoupdate`에 `"hash": {"url": "$url.sha256"}`가 없음 (autoupdate 도구를 쓸 때만 문제)
- 첫 릴리스 커밋에서 `JSON.stringify`가 tauri.conf.json 서식을 바꿈 (동작 차이 없음)
